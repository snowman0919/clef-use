## clef-use implementation contract

For the Reactive Runtime & Agent Enablement implementation, read `KODEX.md`
and `docs/BASELINE_AND_SOURCES.md` before changing behavior. If the handoff
package is outside this repository, resolve its actual location from the user
attachment and retain the correct paths rather than guessing them.

Preserve unrelated work and the active V2 runtime; keep `old/` frozen.
Distinguish instruction-only Agent Skills from executable runtime operations.
Follow the requirement IDs in `ACCEPTANCE.yaml`; record actual evidence in
`docs/EXECUTION_STATUS.md`. Proposed APIs are not available until implemented
and advertised by the live server. Never weaken a guard to obtain a passing run.

Use the connected workspace's real tools and existing permissions. Record
mock, replay, live-desktop, harness, installation, and release verification
separately. Keep restricted avatar assets and private evidence out of Git.
